milestone

noun

意思：里程碑

Releasing the website is a major milestone for the project.

常用在專案管理與人生規劃中，象徵重要的階段性成果。

deployment

noun

意思：部署 / 佈署

The deployment to the cloud server was successful.

軟體開發中，指將程式碼從開發環境發布到正式運行的伺服器上。

boilerplate

noun

意思：樣板程式碼

create-next-app generates a lot of boilerplate code.

指重複出現、可以被複製使用的基礎程式碼結構。

iterative

adjective

意思：迭代的、反覆的

We use an iterative approach to improve the design step by step.

形容透過反覆測試與修改來逐步改善的過程。
