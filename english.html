📅 2026-05-11

🌟 表達與單字

"To be perfectly candid"

坦白地說...（在可能尷尬的情境中表達完全的誠實）

"To be perfectly candid, the food is a bit too salty for my taste."

"candid (adj.)"

意思：坦率的、直白的

記憶技巧：聯想 "candid photo"（偷拍照）— 沒有擺姿勢、呈現真實的一面。

🛠️ 文法修正筆記

Don't need to posing → You don't need to pose

規則：need to 後面接原形動詞 (base verb)，不是動名詞

Be perfectly candid, I think... → To be perfectly candid, I think...

規則：開頭引導語要用不定詞片語 (infinitive phrase)，不是原形

it's really close → Oh, it's so close! / That was almost it!

規則：表達「差一點點」時，母語者會用更生動的反應句，而不是直譯

I have an example to using → I have an example of how to use

規則：example 後面接 of + how to + 動詞，不能直接用 to + V-ing

It conbine → It combines

規則：第三人稱單數 (it) 後面動詞要加 s / es

I'd go to sleep → I'm going to go to sleep / I'm heading to bed

規則：I'd 是 I would 的縮寫（表示假設或過去習慣），不是「我將要」的意思

📅 2026-05-13

🌟 表達與單字

"streamline (v.)"

意思：簡化/優化流程

記憶技巧：想像流線型設計，讓流程像水流一樣順暢。例句: "I want to build a tool to streamline the weekly reporting process."

🛠️ 文法修正筆記

pioneer of the AI → pioneers in AI / a pioneer in the field of AI

規則：修正搭配詞，使用 "pioneer in [field]" 更為自然。

study AI topics during working → study AI topics during work hours / while working

規則：修正時間表達，"during working" 並非標準用法。

it's ok to me → it's okay with me / I'm fine with it

規則：表達同意或沒問題時，慣用 "okay with me"。

provide to others collgues → provide it to my other colleagues / share it with my colleagues

規則：修正拼寫 (colleagues) 並補上受詞。

makes work conveniently $\rightarrow$ makes work more convenient / makes work easier →

規則：使役動詞 make + 受詞 + 形容詞 (convenient)，而非副詞 (conveniently)。

write a letter with English $\rightarrow$ write a letter in English →

規則：語言介質一律使用介系詞 "in"。

meet the formal mail's format $\rightarrow$ follow a formal email format / match the required formal format →

規則：格式建議使用 "follow" 或 "match"，而非 "meet"。

The key to make presentation better is streamline $\rightarrow$ The key to making a presentation better is to streamline the content / streamlining →

規則：'The key to' 後方必須接 V-ing 或名詞。

💡 學習小技巧

  • 📝 每次練習後記下 實際被糾正的句子，比背 100 個單字更有用
  • 🗣️ 把新學的表達 大聲說出來，讓嘴巴習慣英文的發音節奏
  • 🔄 間隔複習：今天學的，明天、三天後、一週後各複習一次
