#nextjs 2026-05-13

🏗️ Next.js + Tailwind CSS 專案初始化

使用 npx create-next-app@latest 建立專案。選擇 TypeScript + Tailwind + App Router 組合。 注意到 Tailwind CSS 已經升級到 v4，最大的變化是：不再使用 tailwind.config.ts 設定檔！

🎯 學到的事：v4 改在 globals.css 裡用 @theme 語法定義自訂顏色，更直覺也更集中。

#css 2026-05-13

🎨 卡比專屬粉色系色盤設計

定義了一套 5 階粉色色盤，讓整個網站擁有統一的、柔和的視覺語言：

  • kirby-bg (#FFF0F3)：極淺粉，網站基底
  • kirby-pink-light (#FFB7C5)：柔和粉，卡片背景
  • kirby-pink-main (#FF8FAB)：主題粉，核心視覺
  • kirby-pink-dark (#E06C84)：深玫瑰粉，文字與對比
  • kirby-white (#FFFFFF)：純白，內容卡片

🎯 心得：限制色階數量（只定義 5 級）讓整體配色更協調，不會出現過多混亂的粉紅色。

#animation 2026-05-13

✨ Framer Motion 動畫整合

引入 framer-motion 為頁面加入流暢的進入/離開動畫。 安裝時遇到一個大坑：npm install framer-motion 意外移除了 337 個相依套件（包含 Tailwind CSS！）。

🔧 解決方案：發現必須使用 npm install --include=dev 來強制安裝 devDependencies。 這是這個環境的特殊行為，一般開發者不太會遇到。

#deployment 2026-05-13

🚀 GitHub Pages 部署踩坑全記錄

這是今天最痛苦但也最有收穫的部分。連續踩了三個大坑：

  1. 坑 1：READ ME 顯示 — 第一次 push 了 Next.js 原始碼，Zeabur 當成純靜態檔，直接顯示 README.md 內容。
  2. 坑 2：路徑迷路 — 改用 output: 'export' 靜態匯出後，忘記設 basePath: '/ks-kirby-website'，導致所有 CSS 和連結 404。
  3. 坑 3：_next 資料夾被封鎖 — 即使設了 basePath，GitHub Pages 對 _next 開頭的資料夾有特殊處理，CSS 仍無法載入。

💡 終極解法：放棄 Next.js 的複雜編譯路徑，直接在 HTML 中引入 cdn.tailwindcss.com，所有樣式 100% 可控。 雖然不是最佳實踐，但在 GitHub Pages 環境下是最穩定的方案。
