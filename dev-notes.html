Next.js App Router 架構筆記

使用 App Router 建立多頁面應用，包含 layout.tsx 全局佈局與 page.tsx 頁面組件。

Next.js 16 使用 App Router 模式。每個資料夾代表一個路由（例如 /milestones），必須包含 page.tsx。layout.tsx 會包裹所有子頁面，適合放 Navbar 等全域組件。

Tailwind CSS v4 @theme 自訂配色

在 Tailwind v4 中使用 @theme 區塊自訂專屬色盤，取代傳統的 tailwind.config.ts。

Tailwind v4 移除了 tailwind.config.ts，改為在 CSS 檔案中直接使用 @theme 語法定義自訂顏色。這樣的好處是設定更集中，且與 CSS 變數原生整合。

Framer Motion 動畫整合

引入 framer-motion 為 React 組件加入流暢的進入、離開與 hover 動畫。

Framer Motion 提供 motion.div 等組件，搭配 initial、animate、exit 屬性控制動畫。適合做頁面轉場、列表交錯動畫、hover 縮放等效果。
